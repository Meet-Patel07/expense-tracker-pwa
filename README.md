# 💰 Expense & Budget Tracker PWA

A lightweight, responsive **Expense & Budget Tracking Progressive Web App (PWA)** for managing personal expenses, income, categories, budgets, and financial activity.

The application is built with **HTML, CSS, and Vanilla JavaScript** and uses the browser's **Local Storage** for client-side data persistence.

## ✨ Features

- 💰 Add and manage expenses
- 💵 Track income
- 📊 Monitor spending and financial activity
- 📁 Expense category management
- 🏷️ Income and expense categories
- 🎯 Category-based budget management
- 📈 View financial summaries
- ✏️ Edit existing transactions
- 🗑️ Delete transactions
- ↩️ Undo supported actions
- 💱 Configurable currency
- 🎨 Light / Dark / Auto theme support
- 📱 Fully responsive interface
- 📲 Installable as a Progressive Web App
- 🔌 Works without a backend
- 💾 Data stored locally in the browser

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **Web Storage API**
- **Service Worker**
- **Web App Manifest**
- **Progressive Web App (PWA)**

No frontend framework or backend server is required.
